# STAY: Iron Vanguard

기계 재해 **보이드**에 맞서는 인조 전사 **아스트라** 부대를 지휘하는 방치형 웹게임.

바닐라 HTML/CSS/JS — 의존성 0, 빌드 없음. `index.html`을 열면 바로 실행됩니다.

## 플레이

- **자동 전투**: 스테이지 무한 진행, 5의 배수마다 보스(30초 제한). 막히면 이전 스테이지 파밍 후 재도전
- **오버드라이브**: 편성에 타입 I·II·III이 모두 있으면 풀 오버드라이브(10초 데미지 ×2.5) 자동 발동
- **모집**: 젬으로 아스트라 획득 (SSR 4%), 중복은 코어(한계돌파, 공격력 +30%/개)
- **방치 보상**: 오프라인 최대 12시간 정산 + 전초기지 자동 수급
